Can You Eat It?

December 2024 - June 2026
Unreal R&D Generalist

DeTails is a narrative adventure game from the studio Can You Eat It?
I was contracted to work as an Unreal Generalist to research and develop some of the underlying game systems, working with the artists and designers on the team to help realize their ideas.
My main contribution was the game's dialogue system, which I implemented using custom C++ widgets.
It features:

  • Integration with Ink
  • Letter-by-letter printing
  • Rich text decorator support
  • Event triggers on print

In addition, I also spent time researching Unreal Engine's Control Rig plugin and developing several prototype rigs for various characters.
