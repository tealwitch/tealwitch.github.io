Project ReMix

PrimeCut Productions

April 2023
Technical Designer

Project ReMix was a prototype mobile app created for use in several of PrimeCut's school workshops.
During the workshops, students would use the app to design their own unique fantastical characters in groups, and then have those characters interact in a basic procedural narrative.
In-game prompts would convey narrative events and prompt group-discussion, which workshop facilitators would use to explore themes around differences between characters, prejudice and inclusion.
I worked as the lead programmer in a small team to develop the prototype, and was responsible for:

  • Character creation system
  • Narrative event system
  • Save file management
  • UI / UX
  • IOS Deployment and Testing
